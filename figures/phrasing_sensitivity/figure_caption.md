**Figure X | Phrasing sensitivity across query operations and analytical perspectives.** Points show the pass rate across three phrasings and three repetitions per question. Each square represents one question; filled squares identify questions that returned the same result across all nine runs, whereas open squares identify questions that were not fully stable. Aggregation and comparison were insensitive to phrasing, whereas ranking and explanation operations showed substantially lower robustness. Product-perspective queries were also less robust than material- and process-perspective queries. Categories are ordered by pass rate within each grouping. The number of questions in each category is shown beside the category label.

Source-data note: pass rate is a run-level metric, whereas full stability is a question-level binary measure. The two encodings intentionally remain visually distinct.
