**Figure X | Per-question robustness across alternative query phrasings.** Cells report the number of correct outputs across three repetitions for the benchmark wording (P0) and two alternative wordings (P1 and P2). Percentages below the phrasing labels give the aggregate pass rate across the 30 runs associated with each wording. Questions are ordered by query operation while retaining their original identifiers. Filled circles identify questions that returned the same result across all nine runs; dashes identify questions that were not fully stable. P1 produced the largest reduction in performance, while ranking and explanation queries showed the strongest sensitivity to wording.

Statistics note: the figure presents paired descriptive counts from three repetitions per wording. No inferential test or confidence interval is applied because the repetitions are not treated as independent question samples.
