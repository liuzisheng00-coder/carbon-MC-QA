**Figure X | Evaluation-set composition and performance by question scope.** **a,** The 150-question evaluation set comprised 90 executable questions (60%) and 60 boundary questions (40%). **b,** Strict pass rate, numeric accuracy and status accuracy are shown for all questions and executable questions. Boundary questions have a strict pass rate of 88.9% and status accuracy of 92.8%. The all-question numeric rate uses 106 reference-bearing cases: 90 executable questions and 16 boundary cases whose numerical reference is an empty-result row count of zero. The executable numeric rate uses 90 questions. Numeric accuracy is not reported separately for the boundary scope and is shown as N/A rather than zero. The displayed sample sizes identify question scopes. Values are descriptive mean rates across three independent runs, and the scopes are nested. No inferential comparison or confidence interval is shown.
